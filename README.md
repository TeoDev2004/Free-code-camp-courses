# 🎨 Diseño Web Adaptable — freeCodeCamp

Este repositorio contiene los proyectos desarrollados como parte de la certificación **Responsive Web Design** de [freeCodeCamp](https://www.freecodecamp.org/), donde se ponen en práctica los fundamentos de HTML5 y CSS3 para construir interfaces adaptables a cualquier tamaño de pantalla.

## 📌 Sobre esta certificación

La certificación de Diseño Web Adaptable cubre:

- Estructura semántica con HTML5
- Estilizado y maquetación con CSS3
- Flexbox y CSS Grid
- Diseño responsive (media queries, unidades relativas, mobile-first)
- Accesibilidad básica en el desarrollo web
- Buenas prácticas de organización de código
